== (3) why q = 2 is exceptional ==

graph              k  deg planar    K_{3,3}?  note
K_5                2    1 False     no        Ko--Park class; only 5 vertices, so no K_{3,3} minor
octahedron         4    2 True      no        planar
dodecahedron       4    2 True      no        planar
icosahedron        4    2 True      no        planar

All four carry Z/2 and none can have a K_{3,3} minor, so the q = 2 case of
the odd-torsion conjecture is false -- which is exactly the point of the dichotomy.

Every non-Z/2 summand in the stored data lives in a graph containing K_{4,5}.
Every other stored torsion summand is Z/2.
