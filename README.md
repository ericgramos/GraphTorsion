# GraphTorsion
A repo of all software developed for computing the homology groups of graph configuration spaces, both ordered and unordered. This software was primarily generated by Claude's Opus 5.5 model through discussions with the authors, Eric Ramos and Nick Wawrykow. All code has been checked by the authors to the best of their ability for correctness. Moreover, the outputs of many of the computations performed with this software have been verified by other mathematicians using their own means. This readme file was entirely written by the authors, but virtually all comments in the individual code files, as well as the readmes describing how the code is to be run were written by Claude.
